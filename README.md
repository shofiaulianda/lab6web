## 🚀 Cara Menjalankan Project

1. Clone atau download repository ini.
2. Buka folder project di Visual Studio Code.
3. Pastikan file `index.html`, `style.css`, dan `script.js` berada dalam folder yang sama.
4. Pastikan ekstensi Live Server sudah terpasang.
5. Klik kanan `index.html`.
6. Pilih **Open with Live Server**.
7. Halaman praktikum akan terbuka di browser.
